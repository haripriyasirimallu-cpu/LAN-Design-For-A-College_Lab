# LAN Design for a College Lab

## 📌 Project Overview

This project presents the design and simulation of a Local Area Network (LAN) for a college computer laboratory using Cisco Packet Tracer. The network is designed to provide reliable communication between multiple computers through a switch and router.

## 🎯 Objectives

* To design a basic LAN for a college laboratory.
* To configure a router and switch for network communication.
* To assign IP addresses to network devices.
* To establish connectivity between computers.
* To test and verify network communication using ping.

## 🛠️ Technologies Used

* Cisco Packet Tracer
* LAN (Local Area Network)
* IPv4 Addressing
* Router and Switch Configuration

## 🌐 Network Design

The network follows a **Star Topology**, where the computers are connected to a central switch. The switch is connected to the router for network communication.

### IP Addressing

* Network: `192.168.1.0/24`
* Router: `192.168.1.1`
* Subnet Mask: `255.255.255.0`

## ⚙️ Configuration

The router and switch were configured using Cisco Packet Tracer. The router interface was assigned an IP address and enabled for communication.

The network connectivity was verified using the `show ip interface brief` command and ping testing.

## 🧪 Testing

Ping testing was performed to verify communication between the connected devices. Successful ping responses confirmed that the network was configured correctly.
